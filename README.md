# Impact Tank Post-Harvest Platform (working title)

Prototype of a simulation-led, quality-aware routing assistant for perishable produce (tomato, Nagpur
orange, onion) in the Nagpur Division, plus an operations layer (traceability, wastage logging,
shelf-life triage, crowd meter, NGO rescue) whose logs can become the trip-level dataset that the decks
say does not exist publicly.

> Status: under construction. See `docs/PROGRESS.md`. Every impact number this software produces is a
> **simulation output, not field-validated**.

Full run instructions are filled in at Phase 7 and verified by running them.
