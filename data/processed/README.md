# Data pack: processed tables

Every table here is **generated by code** (`python tasks.py data`, `python tasks.py graph`) from raw files whose URL,
retrieval time, SHA-256 and licence are in `data/raw/<source>/MANIFEST.json`. Nothing here is hand-edited. Every row
carries `provenance` (REAL_FETCHED · REAL_DERIVED · USER_ENTERED · ASSUMPTION · SYNTHETIC_DEMO) and
`source_manifest_id` (the raw file it came from). Licences: OSM-derived tables are ODbL 1.0 (attribution
"© OpenStreetMap contributors", share-alike); weather is CC BY 4.0 (Open-Meteo); others see `docs/DATA_SOURCES.md`.

## nodes.csv: business nodes (one row per place)
| Column | Meaning |
|---|---|
| node_id | Stable id: `N` + SHA-1(type + source id)[:12] |
| node_type | AssemblyMandi · ReceivingMarket · FarmGatherPoint · TransitStorageNode · NGOSink · ProcessingSink |
| name / name_source | Display name and where it came from (agmarknet_master · osm · osm_place · generated_from_osm_id · fictional_demo) |
| lat, lon | WGS84 coordinates (never hand-typed; see geocode_method) |
| district | Pilot district |
| osm_id | Matched OSM object (node/way/relation) or empty |
| agmarknet_market_name | Exact Agmarknet label for markets |
| geocode_method / geocode_confidence | osm_tag · agmarknet_name_match · manual_review, with the rule-based confidence (docs/GRAPH_BUILD.md) |
| snapped_graph_node / snap_distance_m | Nearest road-graph node and the straight-line distance to it |
| capacity_kg / capacity_source | Empty for all real nodes (no verified source); demo nodes say SYNTHETIC_DEMO |
| provenance / source_manifest_id | As above (FarmGatherPoint rows are ASSUMPTION: origin proxies, not real collection centres) |
| needs_review | True → excluded from routing until reviewed (`reports/nodes_needing_review.csv`) |
| notes | Human-readable trail of how the row was built |

## edges.csv: directed road segments (OSM, simplified)
edge_id (`E<u>_<v>_<key>`) · u, v (OSM node ids) · osm_way_id (`;`-joined if merged) · highway_class · length_m ·
maxspeed_kmh (numeric OSM tag or empty) · speed_kmh_used (effective) · speed_source (osm_maxspeed ·
class_default_ASSUMPTION · mixed:…) · free_flow_time_s · oneway · road_name · provenance · source_manifest_id ·
speed_flag (OUT_OF_PLAUSIBLE_RANGE if outside config/speeds.yaml range; never clipped).

## graph_nodes.csv, od_matrix.csv
Road-node coordinates (graph_node, lat, lon) and free-flow travel time/distance between all routable business nodes
(origin, dest, time_s, dist_m, policy=free_flow_static; includes the access legs, ASSUMPTION A8).

## agmarknet_markets.csv / agmarknet_commodities.csv
Agmarknet 2.0 master list for the six districts (market id, label, district ids) and the verified commodity ids.

## agmarknet_arrivals.csv / agmarknet_arrivals_daily.csv
Owner-exported Daily Price and Arrival Report rows (one per market × commodity × variety × grade × date: min/max/modal
price in Rs./quintal, arrival quantity + unit, arrival_kg) and their daily totals per market × commodity (REAL_DERIVED).
A missing day means "not reported", never zero. `in_pilot_commodity` is False for potato.

## weather_hourly.csv / weather_points.csv
Open-Meteo archive, hourly UTC, 2025-11-01 → 2026-10-18: temperature_2m (°C), relative_humidity_2m (%),
precipitation (mm) for one representative point per district; points file records the grid cell used and snap distance.

## census_2011_district_population.csv
Census 2011 Table A-02 population (persons, males, females) for the six districts. 15 years old.

## benchmarks_nabcons.csv, fao152_table1.csv, crop_shelf_life_refs.csv
NABCONS 2022 farm/market-level loss % (54 crops; market level ≠ transit loss); FAO AGS Bulletin 152 Table 1
(temperature vs relative deterioration); cited reference shelf lives (UC Davis tomato: citation only; HB66 onion and
orange) with the choice made and its caveat.

## osm_pois.csv
OSM features classified as storage / NGO / processing / marketplace candidates inside the division (tag rules in
pipelines/osm_extract.py).

## geo/
`nodes.geojson` and `edges_simplified.geojson` for the map (display-only geometry).
